# 坦克大战 - Battle City

经典坦克大战游戏的 HTML/JavaScript 重制版。

## 游戏说明

- **方向键** (↑↓←→) / WASD: 移动坦克
- **空格键**: 开火
- **Enter**: 开始游戏 / 重新开始
- **P**: 暂停

## 游戏特色

- 26x26 网格地图，包含砖墙、钢墙、树林等多种地形
- 玩家坦克保护基地（鹰/旗帜）
- 敌人 AI 自动索敌和攻击
- 多波次敌人进攻
- 3 条生命，游戏结束可重来
- 多张地图轮换

## 本地运行

直接用浏览器打开 `index.html` 即可畅玩。
